# earth9890 Homebrew Tap

```bash
brew install --cask earth9890/tap/tally
```

| Cask | Description |
|------|-------------|
| `tally` | Local-first, automatic personal time tracker for the macOS menu bar |

Casks point at [GitHub Releases](https://github.com/earth9890/tally/releases).
The app self-updates after install; `brew upgrade` also works once the cask
version is bumped.
